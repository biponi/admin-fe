# Bumblebee Glassmorphism Icon Set

This directory contains the original source assets and extraction trees for the brand icon set.

## Structure

- `icons8-bumblebee-glassmorphism-favicons.zip`: Original downloaded favicon bundle from Icons8.
- `icons8-bumblebee-glassmorphism.zip`: Original downloaded base icon bundle from Icons8.
- `source/favicons/web/`: Extracted multi-size favicons (16px, 32px, 57px, 60px, 70px, 72px, 76px, 96px).
- `source/base/`: Extracted base PNG assets (48px, 96px, 100px).

## Generation Script

All derivative production assets (`public/` and `src/assets/brand/`) are systematically generated from these sources to ensure zero pixelation and optimal density per screen size.
